3. Theory

Depth First Search (DFS):

DFS is a graph traversal algorithm that explores one path as deeply as possible before backtracking.

It uses a Stack data structure or recursion to explore nodes.

Maze Problem:

The Maze Problem consists of finding a valid path from a starting position to a destination while avoiding blocked cells (walls).

Working of DFS:

1. Start from the initial position.
2. Check the available neighbouring positions.
3. Move to an unvisited valid position.
4. Continue exploring until the destination is reached.
5. If a path is blocked, backtrack and try another path.
6. Stop when the destination is found.

4. Algorithm

1. Define the maze with start and goal positions.
2. Initialize a visited set.
3. Start DFS from the initial position.
4. Check all four directions (up, down, left, right).
5. Move only to valid and unvisited positions.
6. If the goal is reached, return the path.
7. If no path is available, backtrack.
8. Display the final path.
