Practical: 8-Queens Problem Using Backtracking Search

1. Aim

To implement Backtracking Search to solve the 8-Queens Constraint Satisfaction Problem using Python.

2. Objectives

1. To understand the concept of Backtracking Search.
2. To understand the 8-Queens problem.
3. To place 8 queens on an 8 × 8 chessboard.
4. To ensure that no two queens attack each other.

3. Theory

The 8-Queens problem is a classical Artificial Intelligence problem in which 8 queens are placed on an 8 × 8 chessboard.

The main condition is that no two queens should attack each other.

Rules:

1. No two queens should be in the same row.
2. No two queens should be in the same column.
3. No two queens should be on the same diagonal.

Backtracking Search:

Backtracking is an algorithmic technique that solves problems step by step. If a selected position is not valid, the algorithm goes back and tries another position.

4. Algorithm

1. Start from the first row.
2. Check each column for a safe position.
3. If the position is safe, place a queen.
4. Move to the next row.
5. Repeat the process until all 8 queens are placed.
6. If no safe position is available, remove the previously placed queen.
7. Try another position until a valid solution is found.
